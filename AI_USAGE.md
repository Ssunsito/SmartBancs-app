# Declaración del Uso de Inteligencia Artificial

Durante el desarrollo de este reto técnico, se utilizaron las siguientes herramientas de IA:

* **Gemini (Google):** Utilizado como apoyo para estructurar los diagramas de arquitectura de microservicios orientados a eventos, redactar la documentación técnica y generar la base de los scripts Docker/IaC.
* **GitHub Copilot / ChatGPT (ajustar según tu caso):** Empleado como asistente de autocompletado de código para la validación de esquemas en FastAPI y la limpieza de datos en el script ETL.
